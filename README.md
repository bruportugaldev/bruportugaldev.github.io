# bruportugaldev.github.io

Site de portfólio pessoal de Bruna Portugal — Product Builder & iniciante em Programação.

Construído com HTML, CSS e JavaScript puros e hospedado via GitHub Pages.

## Estrutura

```
index.html      # markup principal
css/styles.css  # estilos
js/main.js      # interatividade (menu mobile, ano do footer)
```

## Rodando localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático.

## Deploy

Publicado automaticamente via GitHub Pages a partir da branch `main`.
